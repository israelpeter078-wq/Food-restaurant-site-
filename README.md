# FoodieHub React Frontend

A responsive restaurant menu and online ordering frontend built with React and Vite.

## Run on a computer
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build
Run `npm run build`. The production site is generated in `dist/`.

## Features
- Home, About, Menu and Contact sections
- Responsive black and gold design
- Menu category filters
- Add-to-cart, quantity controls and totals
- Contact form validation and demo confirmation

## Important
This is a frontend-only school project demonstration. It does not process payments, send actual orders, or deliver contact messages to a server. Food photos load from Unsplash and require internet access.
